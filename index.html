Como Usar

1. Digite sua fórmula lógica no campo acima

2. Use os exemplos rápidos para preencher automaticamente

3. Clique em "Executar Transformações" para processar

4. Visualize cada etapa no painel à direita

5. Clique no ícone 📋 para copiar qualquer fórmula
